## 使用说明（简要）

1. 打开部署后的网页地址  
2. 在输入框中粘贴课堂实录文本  
3. 点击“开始分析”  
4. 等待生成 AI 教学反思结果  
5. 根据需要复制或导出 PDF 文档  

> 注：分析结果为 **AI 生成内容**，建议结合教师专业判断进行使用。
